# Security Policy

## Supported Versions

Only the latest release on the `main` branch and the live web deployment receive security updates.

| Version | Supported |
| ------- | --------- |
| Latest (`main`) | :white_check_mark: |

## Reporting a Vulnerability

Since Pixel & Toon Studio runs 100% client-side with zero backend servers or cloud uploads, user images and metadata never leave the local browser.

If you discover a security or privacy vulnerability in the web app or desktop build, please report it privately via GitHub Security Advisories (**Security** → **Advisories** → **Report a vulnerability**) rather than opening a public issue. You can expect an initial response within 72 hours.
